1. Dataset Description & Statistics

Benchmark Curation: NarrativeLens AI consolidates two gold-standard computational linguistics benchmarks: UC Berkeley's Measuring Hate Speech (MHS) (13,138 posts) and HateXplain (3,000 posts). The composite benchmark comprises 16,138 carefully annotated samples stratified across 3 distinct classes, demographic target identities, and token-level human rationales.

2. Current Methodology, Models & Workflow

  • Multilingual Transformer Backbone (XLM-RoBERTa): Fine-tuned FacebookAI/xlm-roberta-base (278M parameters) across 100 languages. Its 250k-token SentencePiece vocabulary handles code-mixed and transliterated slang (e.g., Hinglish) without token fragmentation.
  • Focal Loss Optimization: Addressed severe 61:23:16 class imbalance via Focal Loss with focusing parameter γ = 2.0 and class weights α = [0.4, 1.2, 1.8], down-weighting trivial neutral samples and penalizing misclassifications on rare hate speech boundaries.
  • GPU-Accelerated Multimodal Meme OCR: Integrated EasyOCR CUDA pipeline extracts text regions from memes via CRAFT before fusing with textual classification heads.
  • Captum Integrated Gradients: Computes axiomatic token-level feature attribution showing exact mathematical contribution scores for flagged words.
  • Local Ollama LLM Context Arbiter (Qwen3:4b): Evaluates cultural sarcasm, reclaimed in-group slurs, and demographic targeting 100% locally with zero cloud API costs or data leakage.
  • Semantic Clustering & CIB Forecasting: 1024-dimensional BAAI/bge-m3 embeddings stored in PostgreSQL pgvector enable HNSW cosine clustering to track coordinated inauthentic behavior and forecast OSINT civil unrest flareups.

4. Technical Challenges Encountered & Mitigations

  • Severe Class Imbalance: 61% neutral majority caused standard cross-entropy to predict neutral. Mitigation: Implemented Focal Loss (γ=2.0) with dynamic inverse-frequency weighting, improving Hate Speech F1 by +14.2%.
  • Sarcasm & Reclaimed In-Group Slurs: Transformer embeddings alone misclassified self-referential minority vernacular. Mitigation: Introduced secondary local Ollama LLM arbiter (Qwen3:4b) using structured few-shot system prompts to contextualize intent before executing moderation policy.
  • GPU VRAM Constraints (6GB VRAM): Running XLM-RoBERTa, EasyOCR, and a local LLM concurrently caused CUDA OOM. Mitigation: Employs FP16 mixed precision for transformer inference, activates OCR on demand, and utilizes 4-bit quantized GGUF weights via Ollama with active memory offloading.

5. Future Work & Planned Improvements (Milestone 3)

  • End-to-End Multimodal Vision-Language Fusion: Integrate CLIP / SigLIP visual embeddings with cross-attention layers to identify implicit image-text contrast hate (e.g., juxtaposition of animal pictures with ethnic slurs).
  • Real-Time Streaming Ingestion: Implement Apache Kafka and WebSocket listeners to ingest live, public Telegram and Discord channels with sub-second alert dispatch.
  • Retrieval-Augmented Counter-Speech (RAG): Deploy a vector-retrieval counter-narrative generation module utilizing fact-checked repositories to automatically recommend empathetic, de-escalating replies for human community managers.
